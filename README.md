# Formplus GTM Context OS

This repo is the GTM Context OS for [Formplus](https://www.formpl.us), a no-code online form and survey builder. It holds the ICP, positioning, messaging, research and playbooks that power go-to-market work.

Everything here is built from public sources only. Every company fact links to its source.

See `CLAUDE.md` for how the folders work and the rules for working in this repo.
